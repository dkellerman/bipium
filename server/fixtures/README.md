Percussion regression fixtures are decoded copies of the existing public/audio/snare1.mp3 and kick1.mp3 assets. Format: mono signed little-endian PCM16, 48 kHz. Generated with ffmpeg -i INPUT -ar 48000 -ac 1 -f s16le OUTPUT. Tests need no decoder or network. These recordings cover attacks rejected by the former high-frequency threshold. They are not physical-phone microphone recordings.
